# Estructura del proyecto

## src/domain
- Entidades, value objects, invariantes y reglas de negocio.

## src/application
- Casos de uso, servicios de aplicacion y puertos (interfaces).

## src/adapters
- Implementaciones de infraestructura (persistencia, email, auth) y API.

## src/shared
- Utilidades compartidas, errores y types comunes.

## test
- Tests de dominio y aplicacion.
