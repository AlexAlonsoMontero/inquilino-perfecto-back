# Inquilino Perfecto Backend

Backend del portal inmobiliario desarrollado con arquitectura hexagonal y clean code.
Proyecto personal tratado con estandar de producto real.

## Alcance
- Registro, activacion y reactivacion de usuarios
- Login con email o username
- Gestion de inmuebles y anuncios con fotos
- Reservas mensuales con paso a indefinido tras 12 meses
- Resenas de inmuebles e inquilinos
- Administracion global y consultas avanzadas

## Arquitectura
- Dominio aislado en `src/domain`
- Casos de uso y puertos en `src/application`
- Adaptadores en `src/adapters`
- Utilidades compartidas en `src/shared`
